# MARGOTS — Getting Started

## 1. Try the live application

Open: https://meenavignesh-svg.github.io/margots/

## 2. Run locally

```bash
git clone https://github.com/meenavignesh-svg/margots.git
cd margots
python -m http.server 8000 --directory docs
```

Open `http://localhost:8000`.

## 3. Start with a simple sequence

Use a non-sensitive example DNA/RNA/protein sequence and inspect the deterministic results first.

## 4. Explore AI-assisted reasoning

Configure an AI provider only when you understand its data-handling terms. Keep API credentials out of source control and environment logs.

## 5. Verify scientific claims

MARGOTS is an exploration and education tool. AI-generated interpretations should be checked against appropriate databases, primary literature, experimental evidence, and domain expertise.

## 6. Contribute

See `CONTRIBUTING.md`, then use the GitHub issue templates to report bugs or propose scientific features.
