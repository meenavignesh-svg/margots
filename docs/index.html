Margots

Bioinformatics analysis with three separate model backends. Results are shown side by side, not merged.

What it does

  • Sequence stats (GC%, composition, translation attempt, basic protein parameters)
  • Expression / table summaries from CSV or TSV
  • Variant text review
  • Free-form analysis

Classical measurements run first. Each backend gets a different instruction set (strict / contextual / skeptical).

Run locally

git clone https://github.com/meenavignesh-svg/margots.git
cd margots
pip install -r requirements.txt
cp .env.example .env
# add your keys to .env
streamlit run app.py

Required keys

OPENAI_API_KEY=
ANTHROPIC_API_KEY=
XAI_API_KEY=

Any combination works. Missing backends are simply skipped.
