# MARGOTS — Discoverability & Project Guide

## What is MARGOTS?

MARGOTS (**Multi-Agent Molecular Intelligence**) is an open-source, browser-first scientific software project exploring **bioinformatics, computational biology, biotechnology and AI-assisted scientific reasoning**.

## Core capabilities

- DNA, RNA and protein sequence analysis
- GC-content and composition analysis
- Reverse-complement and translation workflows
- ORF and codon analysis
- Biological file workflows
- Multi-provider AI-assisted reasoning
- Side-by-side model comparison
- Browser-first scientific workspace

## Who can use it?

MARGOTS is designed for students, bioinformatics learners, researchers, developers and educators who want to experiment with biological computation and AI-assisted analysis.

MARGOTS is an educational and research-exploration project. AI outputs are advisory and should be verified against appropriate scientific sources and expert review. It is not a clinical diagnostic or treatment system.
